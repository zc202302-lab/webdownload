# webdownload

东方美食电子书采集与 PDF 资料库，运行于 Windows、Python 3.10 及以上。用户自行登录，程序通过网站正常阅读入口采集。

## 运行

1. 下载或克隆仓库，进入 ebook_collector 文件夹。
2. 首次运行 setup.bat 安装依赖；优先使用本机 Edge 或 Chrome。
3. 运行 start.bat，输入起始年份。2021 表示从 2021 年向更早年份处理；all 表示全部。
4. 选择采集方式，默认 1 直接通过杂志目录逐条采集。
5. 浏览器打开后自行登录，选择包含年份标签的杂志栏目，再回到程序窗口按回车。

settings.json 在首次运行时自动生成。也可复制 settings.example.json 为 settings.json 后修改输出位置。升级时保留本机配置、资料库和浏览器专用登录目录。

## 当前行为

- 在选定栏目中按年份从新到旧、逐本处理。
- 默认顺序点击每个杂志目录条目，完整保存后点击弹窗叉号关闭。
- 保存正文图片原文件；图文混排正文滚到底后保留文字、图片并分页生成 PDF。
- 排除网页标题、滚动条、导航、广告和上下章按钮；正文模式提供章节书签。
- 页面正文等待至少 300 秒；原图请求单次最多 300 秒，网络错误或服务器 5xx 最多尝试三次。
- 不限制图片分辨率，但检查图片完整加载、解码和 PDF 有效性。
- 任一本或条目未完成，停止整批并保留进度；重启后校验并跳过已完整保存的内容。
- 成品按年份、刊物和书名分类；提供可搜索、可点击的书库目录。
- 磁盘默认预留 20GB，成功后清理对应临时图片。

详见 [使用说明](ebook_collector/README.md)。

## 测试

安装 ebook_collector/requirements.txt 的依赖和 Node.js，然后在仓库根目录执行 python tests/run_tests.py。

测试使用模拟页面和本地合成图片，不需要网站账户，也不访问网站。覆盖慢加载、正文图片选择、图像字节保留、PDF 页数与书签、容量检查、校验续传、失败停止和目录点击顺序。

网站真实 DOM 和完整图文打印仍需在用户电脑上核验。此前用户已实际采集大量目录条目，也发现并修复过若干超时问题；离线测试通过不表示所有书籍已验证。

## 数据管理

仓库只包含代码、测试与配置示例。登录状态、电子书、采集进度、个人配置和日志保存在本机，不提交 GitHub。复制资料库时保留完整目录结构。
