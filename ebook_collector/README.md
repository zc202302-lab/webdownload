## 独立电子书板块（v1.0.3）

EXE 点击“下载电子书”（源码双击 start_books.bat），自行登录后按提示继续。
从 https://www.easteat.com/book_list.php?category=books 首页开始，向下滚动加载全部书籍，按详情链接中的ID去重。
只有加载更多隐藏、没有加载提示、到底后连续30秒稳定才确认扫描完成；加载错误立即停止，至少300秒无进展仍未确认到底时停止，不将当前列表视为全部。
按查看详情链接进入详情页，点击立即阅读，保存当前页原图后点击阅读器下一页箭头；全部页面校验并生成PDF后点击右上角关闭，确认弹窗隐藏才处理下一本。
输出位于设置的 output_dir/电子书：每本独立PDF，电子书目录.html、电子书记录.json 和 _work 续传进度。
翻页不使用纸面印刷页码，以阅读器页码及实际图片文件名对应页面。启动时如恢复到中间页会先回第1页，再按箭头前进；已保存页校验通过后复用。空白书页保留。
任一本失败、总页数变化、图片缺失或关闭失败即终止；不自动购买或绕过权限。页图至少等待300秒，原图下载每次300秒最多三次。
公开列表自动滚动加载和详情页阅读弹窗结构已在浏览器核查。登录后的阅读器箭头、页面原图和完整书籍下载尚未网站实测；未识别阅读器或箭头时会停止。

## 安装或升级

1. 解压程序到固定文件夹。升级时覆盖程序文件，保留原 output 和 browser_profile 开头的文件夹。
2. 双击 setup.bat。它安装 Python 依赖；程序优先使用本机 Edge/Chrome，无需下载额外浏览器。需要 Python 3.10 或以上。
3. 双击 start.bat，先输入起始年份（例如2020将从2020往更早年份处理）；输入all恢复全部年份，直接回车保留上次选择。然后自行登录网站。在“电子杂志”里选择目标栏目，例如“烹饪艺术家”，确认页面有年份标签。
4. 回到程序窗口按回车。程序从选定的起始年份往更早年份处理；若该年没有标签，则从最接近的更早年份开始；逐本进入“查看目录 → 立即阅读 → here移动版 → 保存PDF”。
5. 打开 output/书库目录.html，搜索书名、年份或状态，点击书名进入PDF。

范围是你在浏览器中选定的杂志栏目，不会自动切换其他栏目。需要处理其他栏目时，再次运行并选择相应栏目。程序不会操作购买按钮；没有阅读入口的书会记录为“无阅读入口”。

## 目录与空间

成品按 年份/刊物名称/书名.pdf 保存。_work 是断点续传的临时区域。书库记录.json 记录完成状态、页数、文件大小和校验值；书库目录.html 是可搜索的书籍总目录。整本阅读器模式只提供书库总目录；目录正文模式会额外生成书内章节书签；已经完整保存的目录条目校验通过后可跳过。

成功生成且通过PDF页数/结构检查后，自动删除该书临时图片。下载或PDF检查失败时保留图片；重新运行可继续。已完成文件通过校验后直接跳过；文件删除或改动时会重新处理。旧版带complete.json的成品会纳入总目录，书名唯一匹配时可跳过重下。

默认预留20GB，程序读取实际磁盘余量，并在每页保存和PDF生成前检查。空间不足立即暂停，保留进度。不能仅凭当前340GB确定能存多少本，实际占用取决于书籍数量和图片大小。失败书籍的临时图片也会占用空间，目录里可查看状态。

## settings.json

- output_dir：资料库位置，默认 output（程序文件夹内）。可改为 D:/电子书资料库 等路径；建议在启动前设好，之后保持一致。
- reserve_gb：默认20，按十进制GB预留。
- years："all"处理当前栏目所有年份，或用[2024]只测试2024年。
- start_year：null表示全部，2020表示仅处理2020及更早年份，启动时可交互设置并自动记住。若years不是all，则处理两项设置的交集。
- keep_page_images：默认false，PDF检查成功后清理临时图片；true则保留原图。

复制资料库到其他设备时保留完整目录结构；PDF可单独放到手机阅读器。若需迁移已下载内容，应移动整个output文件夹，不要只移动书库记录.json。

## 运行与故障

采集期间保持浏览器打开，不手动切换程序正在操作的页面。Ctrl+C可停止。任意一本书未完成即停止整批任务并保留进度，不继续下一本或下一年份；磁盘不足或HTTP401/403/429时暂停。遇到验证码请先停止程序，自行在浏览器处理。失败原因显示在总目录及书库记录.json中。原图分辨率不构成限制，图片仍必须成功下载并完整解码。

程序保存网站实际加载的原图，并保留页面顺序；原图清晰度不会提升。登录状态保存在独立的 browser_profile_msedge/browser_profile_chrome 等目录，不要分享这些目录。

验证范围：已经离线测试PDF生成/检查、临时图片清理、容量保护、总目录链接、文件校验、完成记录恢复、年份排序和批量失败续行。已渲染检查测试PDF；网站全部年份完整采集仍需在你的电脑上实际验证。

## 空白阅读器及目录正文备用模式

启动时选择采集方式：默认1直接进入杂志目录；选择2时使用 auto：整本阅读器超时/空白后重新进入详情页，按杂志目录逐条点击，保存正文后点击弹窗叉号关闭，再打开下一条，只采集弹窗正文图片。可设为 chapters，直接使用目录正文流程，省去整本阅读器等待。

只保存正文图片原文件，排除弹窗标题、上一章/下一章、网站导航及广告。读取网页实际提供的 data-original/srcset 等图片地址，从有效候选里选择像素最大的原图；不猜测高清地址，不使用屏幕截图，不插值放大。分辨率不足不再阻止采集，所有有效原图都会保存并生成PDF；章节像素仍记录在进度和书库记录中。旧settings.json里的chapter_min_short_edge/chapter_min_long_edge不再用于拦截图片。

每章默认最多等待300秒；即使旧设置仍为180秒，新版也会至少等待300秒。chapter_wait_seconds可设置更长时间。等待所有正文图片加载并解码成功，图片列表连续稳定2秒后才下载；下载后再次完整解码校验。某章没加载全就停止这本书并保留进度，下一次可继续。

本模式根据用户截图适配；尚未获得此弹窗的实际网页DOM，因此目录识别需要在你的电脑上实测。未识别时会停止并记录错误，不会截整屏代替。已经通过离线慢加载、正文图片选择、低分辨率接收和原始JPEG嵌入/章节书签测试。

## 可滚动长正文与图文混排

弹窗正文有滚动条时，程序会逐步滚到底，等待图片与正文高度稳定。单张长图下载完整原图，不截取当前可见区域。图文混排章节会保留全部文字及图片，分页为A4正文PDF；删除网页标题、上下章按钮、导航及广告。图文模式的文字由浏览器PDF引擎输出；原始插图不会人为放大，低清原图无法变为高清。图文插图尺寸可能小于整页书页，所以整页图片分辨率门槛只应用于图片式章节。

图文导出需要本机Edge/Chrome支持PDF输出。已离线测试滚动到底、慢图等待、PDF合并和书签页码；当前执行环境未安装本地浏览器，完整图文PDF打印及网站实际DOM尚待你的电脑验证。

目录采集现在使用“逐条点击目录 → 完整保存 → 叉号关闭 → 下一条目录”的流程，不点击下一章按钮。关闭失败也视为未完成并终止整批。已保存的每条章节PDF和原图都有校验记录，重启时校验通过可跳过该条；旧版本没有条目完成记录的进度会重新打开条目检查，但已有图片仍可复用。

原图下载单次最多等待300秒，网络失败或服务器5xx最多尝试3次；401/403/429立即停止。3次仍失败则终止整批并保留进度，错误不打印请求Cookie。
